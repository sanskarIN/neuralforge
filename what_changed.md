## Commit convention

The repository owner requested local Git commit email `sanskarin@outlook.in`. Configure it in local clones with:

```bash
git config user.email "sanskarin@outlook.in"
```

GitHub connector/API-created commits use the identity associated with the linked GitHub account because the connector does not expose a per-commit author-email field.
