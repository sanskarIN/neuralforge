# NeuralForge Storefront

The official Ram Sandesh Gumroad storefront is:

## **https://ramsandesh.gumroad.com**

[![Explore the Ram Sandesh Gumroad Store](assets/gumroad-storefront.svg)](https://ramsandesh.gumroad.com)

Use the storefront to discover available NeuralForge publication editions, previews, companion materials, and other digital publications released by Ram Sandesh.

## Repository and storefront roles

- **GitHub** — open-source companion code, tests, labs, reproducible examples, issues, pull requests, errata, and release engineering.
- **Gumroad** — official storefront destination for published digital products and downloadable publication packages when offered there.

The open-source licensing of repository code remains governed by `LICENSE`. Book/publication rights remain governed separately by `BOOK_LICENSE.md`.

## Durable storefront link

When a GitHub-facing page needs to direct readers to the official store, use this canonical URL exactly:

`https://ramsandesh.gumroad.com`

The SVG badge in `assets/gumroad-storefront.svg` is a custom NeuralForge repository storefront badge. It is not represented as an official Gumroad corporate logo.
