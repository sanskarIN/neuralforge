# Part-by-Part Companion Code

This directory is reserved for the companion implementations for NeuralForge Parts 1-120.

Planned convention:

```text
part-001/
  README.md
  src/
  tests/
  requirements.txt or pyproject.toml
```

Each part should be independently understandable, runnable where practical, and explicit about dependency versions and hardware assumptions. The repository should contain companion code and learning resources, not the complete paid manuscript.
