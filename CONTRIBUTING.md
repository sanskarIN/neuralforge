# Contributing to NeuralForge

Thank you for helping improve the NeuralForge companion repository.

## Official storefront

The official Ram Sandesh Gumroad storefront is **https://ramsandesh.gumroad.com**.

GitHub remains the place for open-source code, issues, tests, reviews, and contributions. Gumroad is the storefront destination for available digital publications and downloadable publication products. See `STORE.md` for the boundary.

## Commit identity

For local commits made by the repository owner, use the requested commit email:

```bash
git config user.email "sanskarin@outlook.in"
```

Set the appropriate Git author name separately with `git config user.name`.

> GitHub API/connector-created commits use the identity provided by the linked GitHub account. Contributors should configure their own truthful Git identity locally.

## Commit style

Prefer small, focused commits. Suggested prefixes:

- `docs:` documentation
- `feat:` new companion feature/project
- `fix:` bug or correction
- `test:` tests and validation
- `refactor:` code restructuring
- `build:` build/release tooling
- `chore:` repository maintenance

## Pull requests

1. Keep each pull request focused.
2. Explain what changed and why.
3. Add or update tests where relevant.
4. Do not commit secrets, credentials, private identity documents, or paid manuscript source files.
5. Respect third-party licenses and attribution requirements.
6. Keep durable project links in documentation; avoid embedding changeable social-media handles in permanent publication artifacts.
7. When a GitHub-facing page references the official storefront, use the canonical URL exactly: `https://ramsandesh.gumroad.com`.
