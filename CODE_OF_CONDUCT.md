# Code of Conduct

NeuralForge is an educational and engineering-focused open-source project. Be respectful, constructive, and specific when discussing code, documentation, bugs, and technical decisions.

## Expected behavior

- Give actionable, technical feedback.
- Assume good intent while still reviewing work carefully.
- Respect different experience levels and backgrounds.
- Keep discussions relevant to the project.
- Credit sources and respect licenses.
- Protect private information and credentials.

## Unacceptable behavior

Harassment, threats, discriminatory abuse, doxxing, spam, deliberate misinformation, or posting private credentials/data are not acceptable.

Project maintainers may remove content or restrict participation when necessary to keep the repository safe and useful.
