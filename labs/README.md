# NeuralForge Labs

This directory is reserved for practical labs that accompany the book.

Each lab should include:

- Learning objective
- Prerequisites
- Reproducible setup
- Runnable implementation
- Expected output or verification method
- Troubleshooting notes
- Tests or assertions when appropriate
- License/attribution notes for any third-party material

Labs should use safe, synthetic, or properly licensed data whenever possible and must not commit secrets or private user data.
