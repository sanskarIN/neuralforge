# Examples

This directory is reserved for small, focused NeuralForge examples that demonstrate one concept at a time.

Examples should prefer:

- Minimal dependencies
- Clear entry points
- CPU-compatible defaults where practical
- Deterministic seeds when useful
- Comments explaining non-obvious tensor shapes and design choices
- Links to official framework documentation for version-sensitive behavior

Large end-to-end projects belong under `labs/` or future capstone directories rather than this folder.
