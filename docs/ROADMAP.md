# NeuralForge Companion Repository Roadmap

## Phase 1 - Repository foundation

- Core documentation and licensing
- Contribution and security policies
- Canonical publication metadata
- Release and social-link policies

## Phase 2 - Part-by-part companion code

Create organized folders for Parts 1-120 with runnable examples, requirements, tests, and short READMEs.

## Phase 3 - Labs and capstones

Add practical labs, reference implementations, datasets/sample generators where licensing permits, and final capstone scaffolding.

## Phase 4 - Reproducibility and CI

Add linting, formatting, unit tests, smoke tests, environment checks, and reproducible dependency definitions.

## Phase 5 - Release engineering

Add tagged releases, release notes, checksums, compatibility matrices, and automated validation for companion code.

## Phase 6 - Maintenance

Maintain `CHANGELOG.md`, errata, dependency updates, security fixes, and versioned compatibility notes without embedding changeable social-media links into permanent ebook copies.
