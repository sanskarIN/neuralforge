# Errata and Corrections Policy

Use GitHub issues for reproducible technical corrections to companion code or documentation. For book corrections, record the issue in the publication errata/change log and fix the canonical manuscript before rebuilding store files.

A useful erratum report should include:

- Part/chapter number
- Section heading
- Short description of the problem
- Corrected behavior/text when known
- Framework/library version if version-sensitive
- Minimal reproduction for code issues

Do not post paid manuscript pages in full. Quote only the minimum text necessary to identify a correction.

When corrected publication files are offered through the official storefront, the canonical Ram Sandesh Gumroad destination is:

**https://ramsandesh.gumroad.com**
