# NeuralForge Publishing Guide

This repository accompanies **NeuralForge - Deep Learning from Zero to Mastery**, Complete 120-Part Master Edition, by **Ram Sandesh**.

The full publication-package guide is maintained with the release artifacts. This repository document records the canonical publishing policy and platform workflow.

## Canonical release files

- EPUB: preferred for reflowable ebook stores
- PDF: fixed-layout master and direct-download edition
- DOCX: editable master/fallback conversion source
- PNG cover: storefront artwork
- Free-preview PDF: optional sample

## Recommended publication order

1. Gumroad for a direct PDF/EPUB bundle.
2. Amazon KDP for Kindle distribution.
3. Google Play Books with EPUB plus PDF when possible.
4. Kobo Writing Life with EPUB.
5. Apple Books with EPUB.
6. Leanpub for an additional technical-book channel.
7. Payhip as an optional direct-download storefront.
8. Draft2Digital only for retailers not already managed directly.

Do not distribute the same edition to the same retailer both directly and through an aggregator unless performing a deliberate migration.

## Durable metadata

- Title: `NeuralForge - Deep Learning from Zero to Mastery`
- Edition: `Complete 120-Part Master Edition`
- Author: `Ram Sandesh`
- Companion repository: `https://github.com/sanskarIN/neuralforge`
- X/Twitter: intentionally omitted

## Release workflow

1. Freeze canonical source.
2. Build PDF, EPUB, and DOCX outputs.
3. Scan all outputs for stale social links.
4. Validate PDF navigation and EPUB structure.
5. Check representative early, middle, and final parts.
6. Update metadata, changelog, and checksums.
7. Upload to storefronts.
8. Record live listing URLs in a private release ledger rather than hard-coding changeable links into the ebook.

## Account and legal eligibility

Never falsify age, identity, tax, bank, or publisher information. Store eligibility and contracting rules vary and can change; verify the current official terms immediately before publication. If the intended publisher is not legally eligible to hold an account, use an authorized adult only when the platform's current terms permit it.
