The canonical Gumroad destination for NeuralForge publication releases and other Ram Sandesh digital products is:

## Repository usage

Use the canonical store URL in public-facing GitHub documentation where readers may reasonably look for the book, publication releases, related digital products, support/purchase guidance, or publishing information.

Recommended Markdown link:

```markdown
[Ram Sandesh on Gumroad](https://ramsandesh.gumroad.com)
```

Recommended highlighted badge:

```markdown
[![Visit Ram Sandesh on Gumroad](https://img.shields.io/badge/Gumroad-Ram%20Sandesh-FF90E8?style=for-the-badge&logo=gumroad&logoColor=000000)](https://ramsandesh.gumroad.com)
```

## Scope

The link belongs in reader-facing documentation, release/publishing guidance, support surfaces, metadata, issue/PR guidance where relevant, and implemented Part READMEs.

Do **not** insert promotional links into Python source modules, unit tests, generated numerical output, machine-readable dependency files, or code examples when the link has no technical purpose.

## Link stability

If the storefront ever changes, update this policy, the repository validator, and all public-facing references together in one reviewed change.
